# Quick GitHub upload

1. Extract this ZIP on your phone.
2. Open your GitHub repository.
3. Upload/replace the extracted files at the repository root.
4. Make sure `.github/workflows/build-apk.yml` is uploaded exactly in that path.
5. Commit the changes.
6. Open Actions > Build Android APK and run the workflow.
7. After a successful build, open the completed workflow > Artifacts > StegaSuite-debug-apk.
