What is StegaSuite?An open-source tool for secure file hiding on Android & Windows

StegaSuite is an open-source app that hides any file inside other files using Steganography. Unlike regular encryption, which only encrypts the content, StegaSuite also hides the very existence of the hidden file — anyone viewing the carrier file has no idea anything is hidden inside!

💡 Why steganography? Regular encryption (like a passworded ZIP) advertises that something is encrypted. Steganography hides the encrypted file inside a completely ordinary file (e.g. a photo). Nobody without the right tool can even tell something is hidden!

How to hide a fileStep by step, from picking files to saving the output

Step 1: Carrier file Carrier

The carrier is the file your secret will be hidden inside. After hiding, it still looks completely normal.

  1. Open the app. By default it is on "Hide" mode.
  2. In the first card, click "Pick carrier file".
  3. Choose a file from the system picker (image, audio, video, PDF, ...).
  4. File info is shown: format type, name, size, and hiding capacity.
⚠️ Lossy formats warning If the carrier is JPEG, WebP or another lossy format, an orange warning is shown. These formats may corrupt the hidden data. For best results use PNG or BMP.

Step 2: Payload file Payload

You can hide anything: text, images, audio, video, PDF, ZIP, anything.

  1. In the second card, click "Pick payload file".
  2. Select the file you want to hide.
  3. Its name and size are displayed.
✅ No format limitsThere is no restriction on the payload type. Any file with any extension can be hidden.

Step 3: Password optional

A password encrypts the hidden file with AES-256 on top of hiding it. This extra layer is called defense in depth.

  1. Type a password in the third card.
  2. Click the eye icon 👁️ to show/hide it.
  3. Leave it empty and the file is stored with CRC32 only (no encryption).
⚠️ Don't forget your password! If you forget it, the hidden file cannot be recovered. Write it down somewhere safe.

Step 4: Save the output save

  1. Click "Hide & Save".
  2. Wait for the operation to finish (usually a few seconds).
  3. The output is saved with (st) added to the name, e.g. photo(st).png.
  4. Click the saved-file link to open it.

How to extract a hidden fileRecovering the file from inside the carrier

Extraction steps easy

  1. Tap the open lock 🔓 icon at the top to switch to "Extract" mode.
  2. Select the carrier that contains the hidden file.
  3. If it was hidden with a password, enter it.
  4. Tap "Extract hidden file".
  5. The extracted file is saved and shown.
💡 Automatic detection The app detects the hidden file via Magic Bytes, not the file extension. Even if you rename the carrier or change its extension, extraction still works!

Step 0: Login / account Windows only

The app does not open without login (fullscreen login screen):

  1. Sign up: username + password + confirm → "Create account".
  2. Save the one-time recovery code immediately! With it + the backup file (*.stegabak) you can recover a forgotten password.
  3. Log in: username + password, or the Google button (system browser + PKCE).
  4. Backup: ⚙️ Settings → export backup (AES-256-GCM encrypted). Language/theme are stored per user.

Hiding on Windows 🏠 Home tab

  1. In the capsule sidebar click 🏠 Home (default).
  2. In the "Carrier file" card click Browse... — or drag & drop a file into the field.
  3. Format, name, size and capacity are displayed.
  4. Pick the payload in the second card (any format, no limits).
  5. Set a password (recommended — 👁️ toggles visibility) or leave empty (CRC32 only).
  6. Click "Hide & Save"; the suggested name carries (st), e.g. photo(st).png. The op is logged in History.
⚠️ Lossy formatsOn Windows too, prefer PNG / BMP / WAV; JPEG and WebP may destroy the data.

Extracting on Windows 🔓 Extract tab

  1. In the sidebar click 🔓 Extract.
  2. Pick the carrier (drag & drop works).
  3. Enter the password if one was set.
  4. Click "Extract Hidden File" — the file is saved with its original name and extension.
💡 Other tabs:ℹ️ About • ✉️ Contact • ❤️ Support • ⚙️ Settings (5 languages: Persian, Arabic, English, Russian, Chinese + 9 dark/light themes).

Encryption detailsHow your file is protected

Layer 1: Hiding (Steganography) LSB

The payload is stored in the least significant bits of the carrier — too small to see or hear with normal tools.

Images
Last bit of each RGB channel changes. Max color shift: 1/255.
Audio
LSB of each sample changes. Inaudible to the human ear.
Generic files
Last bit of each byte after the file header changes.

Layer 2: Encryption AES-256-GCM

If a password is set, data is encrypted with AES-256-GCM before hiding:

ParameterValueNotes
AlgorithmAES/GCM/NoPaddingauthenticated encryption

Security warnings read me

  • Don't forget your password: recovery is impossible without it.
  • Use a strong password: mix letters, digits and symbols.
  • Keep the carrier: it is the only key to your hidden file.
  • Don't share directly: email/messenger may compress or edit the carrier.
  • Back up: always keep a copy of the carrier.

Best practices recommended

  • ✅ Use PNG — best format, no quality loss, no corruption risk.
  • ✅ Set a strong password — extra layer even if hiding is discovered.
  • ✅ Don't modify the carrier — any edit/compression may corrupt data.
  • ❌ Don't use JPEG — lossy, may destroy the hidden data.
